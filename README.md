# 運行ノート — 運行指示書管理アプリ

一般貨物自動車運送事業の長距離フリー便向け、React / TypeScript / Vite のPWA初期版です。会社と運転者の変更記録を版ごとに保存します。

**現在はデモ検証段階です。** Supabaseは未作成・未接続です。環境設定なしで起動するデモに実データを入力しないでください。本番利用や法令適合を認証するものではありません。

## 起動

Node.js 22.12以上（推奨22 LTS）、npmを使用します。

```sh
npm ci --ignore-scripts
npm run dev
```

本番ビルドをローカルで確認する場合：

```sh
npm test
npm run test:db
npm run build
npm run preview
```

## 実装した機能

- 運行の下書き作成・編集、日付・運転者・車両・運行IDによる検索
- 荷物申請、差戻し・却下、積卸先の下書き反映
- 運行管理者による発行、旧版と新版の差分、発行済みスナップショットと会社写しの固定
- 直接対話の実日時・担当者・相手・内容、本人の変更記録、端末保存通知を別管理
- 旧版確認の流用拒否、下書きrevisionとbase_versionの照合、操作IDによる再送防止
- 休憩と休息、予定と実績、出庫・帰庫と勤務開始・終了の区別
- 必須項目・時刻順序・144時間超過の発行前検証（他の改善基準は判定不能）
- IndexedDB保存、未送信キュー、再接続時の同期、競合時の内容を保持した再確認
- 版別の印刷・PDF保存、CSV、全版と双方記録のJSON出力
- Supabase Authログイン、営業所・本人・役割のRLS、認証付きトランザクションRPC
- 保存確定後の変更拒否、保存期限と3年の社内方針表示、発行版・会社写し・監査記録の更新／削除防止
- GitHub Actionsによるテスト・ビルドとデモビルドの成果物保存

デモ役割切替は架空データの確認用です。クラウドモードでは認証済みの所属情報から役割を取得します。片方だけの接続設定や秘密キーの誤設定を検知した場合は起動を止めます。

## クラウド接続

[Supabaseセットアップ手順](docs/setup.md)を参照してください。会社名義のプロジェクト、個別ユーザー、バックアップ設定等が必要です。DB変更は検証用プロジェクトで確認してから適用します。

```env
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR-PUBLISHABLE-KEY
```

`VITE_`変数はブラウザに公開されます。secret / service_role / GitHubトークンを入れないでください。

## 本番前に残る作業

認証付き実サービスでの結合テスト、端末の機内モード検証、Androidのホーム画面追加検証、電子携行の具体的運用の確認が必要です。添付Storage、利用者招待画面、サーバーで固定保管する版別PDF、勤怠データ連携と全改善基準判定、通知・OCR・フェリー控除は未実装です。

JSONを会社PCに保存する機能はバックアップの補助です。日次DBバックアップ・独立した保存先への出力・復元検証を別途設定してください。削除APIはありません。DB管理者の操作が絶対に改変不可能とは主張しません。

GitHub Pagesへの公開は行っていません。privateリポジトリからのPagesには契約条件があり、Pages画面の公開範囲とDBデータの権限は別です。

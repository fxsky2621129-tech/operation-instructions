# スマホのホーム画面に追加

AndroidのChromeで[運行ノートの公開デモ](https://fxsky2621129-tech.github.io/operation-instructions/)を開く。PCの起動や同じWi-Fiへの接続は不要です。Supabaseは未接続のため、デモデータは各端末内に保存され、スマホとPCの間で同期されません。実データは入力しないでください。

- iPhone：Safariの共有メニュー →「ホーム画面に追加」→ 名前「運行ノート」を確認 →「追加」。
- Android：Chromeのメニュー「⋮」→「ホーム画面に追加」→「追加」（HTTPS公開後は「インストール」と表示される場合もある）。

ホーム画面の追加操作はスマホで行う。iPhone用180px、Android用192px・512pxのPNGアイコンを同梱。

## 同じWi-Fi内のデモ

今回のPCのWi-Fiアドレスは192.168.1.40。プレビュー起動中は `http://192.168.1.40:4176/` で開く。スマホを同じWi-Fiに接続し、PCを起動しておく。会社PCのファイアウォールやゲストWi-Fiでは到達できない場合がある。PCのIPが変わるとアドレスも変わる。

このHTTPアドレスはデモ用で、ホーム画面のショートカットとして利用する。Service Workerによるオフライン起動・PWAインストールにはHTTPSの公開先が必要。スマホとPCのデモデータは同期されない。実データは入力しない。

継続利用にはHTTPSの配信先を設定し、共同利用する場合は[Supabaseセットアップ](setup.md)も完了する。ホーム画面への追加・機内モード動作は実機で確認する。
